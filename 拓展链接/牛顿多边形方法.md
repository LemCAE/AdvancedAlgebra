## 基本概念

```ad-def
title: 牛顿多边形
**牛顿多边形**是数论和代数几何中的一种工具，用于分析多项式的[[p-adic性质]]。它将多项式的系数与指数关联起来，通过凸包分析来推断多项式的不可约性和根的性质。
```

---

## 构造方法

### **基本构造步骤**

```ad-def
title: 牛顿多边形的构造
对于多项式 $f(x) = a_nx^n + a_{n-1}x^{n-1} + \cdots + a_1x + a_0 \in \mathbb{Z}[x]$，固定素数 $p$：

1. **绘制点集**：对于每个非零系数 $a_i \neq 0$，在平面上绘制点 $(i, v_p(a_i))$，其中 $v_p(a_i)$ 是 $a_i$ 的 $p$-adic 赋值（即 $a_i$ 中 $p$ 的指数）

2. **构造下凸包**：这些点的下凸包（即从下方支撑这些点的最小凸集）就是牛顿多边形
```

```ad-example
title: 牛顿多边形构造示例
考虑 $f(x) = 2x^4 + 3x^3 + 5x^2 + x + 6$，取 $p=2$：

计算 $v_2(a_i)$：
- $a_4=2$：$v_2(2)=1$，点 $(4,1)$
- $a_3=3$：$v_2(3)=0$，点 $(3,0)$
- $a_2=5$：$v_2(5)=0$，点 $(2,0)$
- $a_1=1$：$v_2(1)=0$，点 $(1,0)$
- $a_0=6$：$v_2(6)=1$，点 $(0,1)$

连接这些点的下凸包得到牛顿多边形。
```

## 理论基础

### **p-adic 赋值**

```ad-def
title: p-adic 赋值
对于整数 $a$ 和素数 $p$，$v_p(a)$ 定义为满足 $p^k \mid a$ 的最大整数 $k$。

性质：
- $v_p(ab) = v_p(a) + v_p(b)$
- $v_p(a+b) \geq \min(v_p(a), v_p(b))$
- 如果 $v_p(a) \neq v_p(b)$，则 $v_p(a+b) = \min(v_p(a), v_p(b))$
```

### **牛顿多边形定理**

```ad-lemma
title: 牛顿多边形基本定理
牛顿多边形的每条边的斜率对应着多项式在 $p$-adic 域中根的 $p$-adic 赋值的负值。

具体来说，如果一条边连接点 $(i, v_p(a_i))$ 和 $(j, v_p(a_j))$，其斜率为：
$$-\frac{v_p(a_j) - v_p(a_i)}{j - i}$$

则多项式有 $j-i$ 个根，其 $p$-adic 赋值等于该斜率的绝对值。
```

## 在不可约性判定中的应用

### **爱森斯坦判别法的推广**

```ad-lemma
title: 牛顿多边形不可约性判别法
如果对于某个素数 $p$，多项式 $f(x)$ 的牛顿多边形只有一条边，且该边对应的斜率分母与多项式次数互质（即 $\gcd(\text{分母}, n) = 1$），则 $f(x)$ 在 $\mathbb{Q}$ 上不可约。
```

```ad-example
title: 牛顿多边形判别法示例
考虑 $f(x) = x^3 + 2x^2 + 4x + 8$，取 $p=2$：

点集：$(3,0), (2,1), (1,2), (0,3)$

牛顿多边形只有一条边从 $(0,3)$ 到 $(3,0)$，斜率为：
$$-\frac{0-3}{3-0} = 1$$

斜率分母为 $3$，与多项式次数 $3$ 的 $\gcd(3,3)=3 \neq 1$，**不能**判定不可约。

实际上 $f(x) = (x+2)^3$，可约。
```

### **更一般的判别准则**

```ad-lemma
title: 戴森判别法 (Dyson's Criterion)
如果对于每个素数 $p$，多项式 $f(x)$ 的牛顿多边形都只有一条边，则 $f(x)$ 在 $\mathbb{Q}$ 上不可约。

这是牛顿多边形方法的强形式。
```

## 多素数分析

### **综合多个素数的信息**

```ad-lemma
title: 多素数牛顿多边形方法
通过分析多项式在不同素数 $p$ 下的牛顿多边形，可以获取关于多项式因式分解的更多信息：

1. 如果存在素数 $p_1, p_2, \ldots, p_k$，使得对应的牛顿多边形都表明不可能有真因子，则多项式不可约
2. 不同素数提供的因子次数信息可以交叉验证
```

```ad-example
title: 多素数分析示例
考虑 $f(x) = x^4 + 2x^3 + 4x^2 + 8x + 16$

- 对于 $p=2$：点 $(4,0), (3,1), (2,2), (1,3), (0,4)$，一条边，斜率 $1$，分母 $4$
- 对于 $p=3$：点 $(4,0), (3,0), (2,0), (1,0), (0,0)$，一条边，斜率 $0$，分母 $1$

综合信息表明 $f(x)$ 不可约。
```

## 与其他方法的联系

### **与模约简测试的关系**

```ad-lemma
title: 牛顿多边形与模约简的联系
牛顿多边形方法可以看作是模约简测试的强化版本：

- **模约简测试**：关注多项式模 $p$ 的分解
- **牛顿多边形**：关注 $p$-adic 性质，包含更多信息

牛顿多边形可以检测到模约简测试可能漏掉的一些不可约情况。
```

### **与爱森斯坦判别法的关系**

```ad-lemma
title: 牛顿多边形推广爱森斯坦判别法
爱森斯坦判别法是牛顿多边形方法的特例：

如果存在素数 $p$ 使得牛顿多边形是从 $(0,1)$ 到 $(n,0)$ 的单一边（斜率为 $-1/n$），则满足爱森斯坦条件。

牛顿多边形方法可以处理更复杂的情况，如系数有多个素因子。
```

## 局限性

```ad-lemma
title: 牛顿多边形方法的局限性
1. **充分非必要**：只能证明不可约性，不能证明可约性
2. **计算复杂性**：需要分析多个素数，计算量较大
3. **特殊情况**：对于某些多项式，可能找不到合适的素数
4. **实现难度**：需要精确的p-adic计算
```
