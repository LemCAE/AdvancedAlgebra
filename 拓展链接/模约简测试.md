# 多项式不可约性的模约简测试

## 基本概念

```ad-def
title: 模约简测试 (Modular Reduction Test)
对于整系数多项式 $f(x) \in \mathbb{Z}[x]$，通过将其系数对某个素数 $p$ 进行[[模运算]]约简得到 $\bar{f}(x) \in \mathbb{F}_p[x]$，利用有限域上多项式的性质来推断原多项式在 $\mathbb{Q}$ 上的不可约性。
```

---

## 基本定理

### 主要定理
```ad-lemma
title: 模约简测试基本定理
设 $f(x) \in \mathbb{Z}[x]$ 是首一多项式，$p$ 是素数且 $p \nmid \text{lc}(f)$（ $\text{lc}(f)$ 指 $f(x)$ 的首项系数(Leading Coefficient)）。如果 $\bar{f}(x) = f(x) \bmod p$ 在 $\mathbb{F}_p[x]$ 中不可约，则 $f(x)$ 在 $\mathbb{Q}[x]$ 中也不可约。
```

```ad-tip
title: p元有限域 $\mathbb{F}_p$
$\mathbb{F}_p$ 是由 $p$ 个元素构成的有限域，其中 $p$ 是素数。它定义为整数模 $p$ 的剩余类环：

$$\mathbb{F}_p = \mathbb{Z}/p\mathbb{Z} = \{0, 1, 2, \ldots, p-1\}$$

其中的运算为模 $p$ 的加法和乘法。
```

```ad-proof
collapse: closed
**证明思路**：
假设 $f(x)$ 在 $\mathbb{Q}[x]$ 中可约，则由高斯引理，存在 $g(x), h(x) \in \mathbb{Z}[x]$ 使得 $f(x) = g(x)h(x)$，且 $\deg g, \deg h < \deg f$。

模 $p$ 约简得 $\bar{f}(x) = \bar{g}(x)\bar{h}(x)$，其中 $\deg \bar{g} = \deg g$，$\deg \bar{h} = \deg h$（因为 $p \nmid \text{lc}(f)$）。

这与 $\bar{f}(x)$ 在 $\mathbb{F}_p[x]$ 中不可约矛盾。
```

## 具体测试方法

### 1. 直接模约简测试
```ad-def
title: 直接模约简测试步骤
1. 选择素数 $p$，满足 $p \nmid \text{lc}(f)$
2. 计算 $\bar{f}(x) = f(x) \bmod p \in \mathbb{F}_p[x]$
3. 检查 $\bar{f}(x)$ 在 $\mathbb{F}_p$ 上是否不可约
4. 如果不可约，则 $f(x)$ 在 $\mathbb{Q}$ 上不可约
```

```ad-example
title: 直接测试示例
证明 $f(x) = x^3 + x + 1$ 在 $\mathbb{Q}$ 上不可约：

取 $p = 2$，则 $\bar{f}(x) = x^3 + x + 1 \in \mathbb{F}_2[x]$

在 $\mathbb{F}_2$ 上验证：
- $\bar{f}(0) = 1 \neq 0$
- $\bar{f}(1) = 1 + 1 + 1 = 1 \neq 0$

由于 $\deg \bar{f} = 3$ 且无一次因式，在 $\mathbb{F}_2$ 上不可约。

因此 $f(x)$ 在 $\mathbb{Q}$ 上不可约。
```

## 高级技巧

### 1. 多素数测试
```ad-lemma
title: 多素数模约简测试
如果对于多个不同的素数 $p_1, p_2, \ldots, p_k$，多项式 $\bar{f}(x) \in \mathbb{F}_{p_i}[x]$ 的不可约因子次数模式相同，且这个模式与任何真分解都不兼容，则 $f(x)$ 在 $\mathbb{Q}$ 上不可约。
```

### 2. 次数分析技巧
```ad-lemma
title: 模约简次数分析
设 $f(x) \in \mathbb{Z}[x]$ 是 $n$ 次多项式。如果存在素数 $p$ 使得 $\bar{f}(x)$ 在 $\mathbb{F}_p[x]$ 中有一个 $m$ 次不可约因子，且 $m$ 是素数且 $m > n/2$，则 $f(x)$ 在 $\mathbb{Q}$ 上不可约。
```

```ad-example
title: 次数分析示例
考虑 $f(x) = x^5 + 2x + 6$

取 $p = 3$，则 $\bar{f}(x) = x^5 + 2x \in \mathbb{F}_3[x]$

分解：$\bar{f}(x) = x(x^4 + 2)$

在 $\mathbb{F}_3$ 上检查 $x^4 + 2$ 不可约（验证无根且不能分解为二次式乘积）。

由于有 4 次不可约因子且 $4 > 5/2$，所以 $f(x)$ 在 $\mathbb{Q}$ 上不可约。
```

## 实际应用策略

### 1. 素数选择策略
```ad-example
title: 有效素数选择
- 选择较小的素数便于计算
- 尝试多个素数以提高可靠性
- 避免选择使得多项式有重根的素数（即 $p \nmid \text{disc}(f)$）
```

### 2. 有限域分解算法
```ad-lemma
title: 有限域多项式分解方法
在 $\mathbb{F}_p$ 上检查不可约性的常用算法：
1. **[[有限域分解算法#1. 试除法 (Trial Division)|试除法]]**：检查是否有一次因式（即是否有根）
2. **[[有限域分解算法#2. 平方自由分解 (Square-Free Factorization)|平方自由分解]]**：去除重因式
3. **[[有限域分解算法#3. 不同次数因子分解 (Distinct Degree Factorization, DDF)|不同次数因子分解]]**：分离不同次数的因子
4. **[[有限域分解算法#4. Cantor-Zassenhaus 算法|Cantor-Zassenhaus]]** 或 **[[有限域分解算法#5. Berlekamp 算法|Berlekamp]]** 算法：完全分解
```

## 注意事项与局限性

### 1. 测试的局限性
```ad-lemma
title: 模约简测试的局限性
- **充分非必要**：如果 $\bar{f}(x)$ 可约，不能得出 $f(x)$ 可约的结论
- **例外情况**：存在在 $\mathbb{Q}$ 上不可约但在所有 $\mathbb{F}_p$ 上可约的多项式
- **首项系数**：必须保证 $p \nmid \text{lc}(f)$
```

### 2. 经典反例
```ad-example
title: 模约简测试失败的情况
多项式 $f(x) = x^4 + 1$ 在 $\mathbb{Q}$ 上不可约，但对于任意素数 $p$，$f(x)$ 在 $\mathbb{F}_p$ 上都是可约的。

这表明模约简测试只能证明不可约性，不能证明可约性。
```

## 与其他方法的结合

### 1. 模约简与数值方法结合
```ad-lemma
title: 结合使用策略
1. 先用模约简测试尝试证明不可约
2. 如果失败，尝试爱森斯坦判别法
3. 考虑使用约化模不同素数并比较因子次数模式
4. 最后可借助数值方法寻找有理根
```
