## 第一数学归纳法
第一数学归纳法是最基本的形式，用于证明一个命题对所有自然数 $n$（通常从 $n = 1$ 开始）都成立。它包含两个步骤：
1. **基础步骤**：证明当 $n = 1$（或起始值）时命题成立。
2. **归纳步骤**：假设当 $n = k$ 时命题成立（称为归纳假设），然后证明当 $n = k + 1$ 时命题也成立。

如果这两个步骤都成功，那么命题对所有自然数 $n$ 都成立。

```ad-example
我们要证明：$1 + 2 + 3 + \cdots + n = \frac{n(n+1)}{2}$ 对所有自然数 $n$ 成立。

- **基础步骤**：当 $n = 1$ 时，左边是 $1$，右边是 $\frac{1 \times (1+1)}{2} = 1$，两边相等，命题成立。
- **归纳步骤**：假设当 $n = k$ 时命题成立，即 $1 + 2 + \cdots + k = \frac{k(k+1)}{2}$。现在考虑 $n = k + 1$：
$$ 1 + 2 + \cdots + k + (k+1) = \frac{k(k+1)}{2} + (k+1) = \frac{k(k+1) + 2(k+1)}{2} = \frac{(k+1)(k+2)}{2}$$
  右边正是 $\frac{(k+1)((k+1)+1)}{2}$，所以命题对 $n = k + 1$ 也成立。

因此，根据第一数学归纳法，该公式对所有自然数 $n$ 成立。
```

## 第二数学归纳法
第二数学归纳法（也称为强归纳法）与第一数学归纳法类似，但归纳假设更强。它同样用于证明自然数上的命题，步骤包括：
1. **基础步骤**：证明当 $n = 1$（或起始值）时命题成立（有时需要证明多个基础情况）。
2. **归纳步骤**：假设当 $n \leq k$ 时命题都成立（即对于所有从 $1$ 到 $k$ 的自然数，命题成立），然后证明当 $n = k + 1$ 时命题也成立。

如果这两个步骤成立，那么命题对所有自然数 n 都成立。

```ad-example
考虑序列定义：$a_1 = 1，a_2 = 2$，且对于 $n > 2$，有 $a_n = 2a_{n-1} - a_{n-2}$。我们要证明 $a_n = n$ 对所有自然数 $n$ 成立。

- **基础步骤**：
  - 当 $n = 1$ 时，$a_1 = 1$，命题成立。
  - 当 $n = 2$ 时，$a_2 = 2$，命题成立。
- **归纳步骤**：假设对于所有 $n \leq k$（其中 $k \geq 2$），有 $a_n = n$。现在考虑 $n = k + 1$：
$$a_{k+1} = 2a_k - a_{k-1} = 2 \times k - (k-1) = 2k - k + 1 = k + 1$$
  所以命题对 $n = k + 1$ 也成立。
```

因此，根据第二数学归纳法，$a_n = n$ 对所有自然数 $n$ 成立。

## 总结
- **第一数学归纳法**适用于证明步骤中只依赖前一个情况（$n = k$）的命题。
- **第二数学归纳法**适用于证明步骤中可能依赖多个前情况（$n \leq k$）的命题，例如在递归定义或分解问题中。
