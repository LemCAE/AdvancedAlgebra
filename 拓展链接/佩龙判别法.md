# 佩龙判别法 (Perron's Criterion)

## 基本概念

```ad-def
title: 佩龙判别法
**佩龙判别法**是判断整系数多项式在有理数域上不可约性的一个充分条件判别法，由德国数学家奥斯卡·佩龙(Oskar Perron)提出。它通过检查多项式的系数来判定不可约性，特别适用于"主导项"明显的多项式。
```

---

## 基本定理

### 标准佩龙判别法
```ad-lemma
title: 佩龙判别法（标准形式）
设 $f(x) = x^n + a_{n-1}x^{n-1} + \cdots + a_1x + a_0 \in \mathbb{Z}[x]$ 是首一多项式。如果满足：

$$|a_{n-1}| > 1 + |a_{n-2}| + |a_{n-3}| + \cdots + |a_0|$$

则 $f(x)$ 在 $\mathbb{Q}$ 上不可约。
```

### 推广形式
```ad-lemma
title: 佩龙判别法（推广形式）
设 $f(x) = x^n + a_{n-1}x^{n-1} + \cdots + a_1x + a_0 \in \mathbb{Z}[x]$。如果存在某个 $k$（$1 \leq k \leq n-1$）使得：

$$|a_k| > 1 + \sum_{j \neq k} |a_j|$$

则 $f(x)$ 在 $\mathbb{Q}$ 上不可约。
```

---

## 证明思路

```ad-proof
collapse: closed
**证明概要**：

1. **反证法**：假设 $f(x)$ 可约，则 $f(x) = g(x)h(x)$，其中 $g(x), h(x) \in \mathbb{Z}[x]$ 都是次数小于 $n$ 的首一多项式。

2. **根的估计**：由韦达定理，$g(x)$ 和 $h(x)$ 的根的模长乘积等于常数项的绝对值。

3. **主导系数的影响**：佩龙条件保证了多项式在单位圆外恰好有一个根（主导根），其余根都在单位圆内。

4. **矛盾**：如果 $f(x)$ 可约，则每个真因子必须包含这个主导根，但这是不可能的，因为真因子的次数小于 $n$，而主导根是唯一的模长大于1的根。

5. **得出结论**：因此 $f(x)$ 必须不可约。
```

## 应用示例

### 示例1：标准情况
```ad-example
title: 满足佩龙条件的多项式
考虑 $f(x) = x^5 + 5x^4 + 2x^3 - x^2 + 3x + 1$

检查佩龙条件：
- $|a_{n-1}| = |5| = 5$
- $1 + |a_{n-2}| + |a_{n-3}| + |a_{n-4}| + |a_0| = 1 + 2 + 1 + 3 + 1 = 8$

由于 $5 < 8$，**不满足**佩龙条件。

但考虑 $f(x) = x^5 + 10x^4 + 2x^3 - x^2 + 3x + 1$：
- $|a_{n-1}| = |10| = 10$
- $1 + 2 + 1 + 3 + 1 = 8$

由于 $10 > 8$，满足佩龙条件，因此这个多项式在 $\mathbb{Q}$ 上不可约。
```

### 示例2：推广形式应用
```ad-example
title: 使用推广的佩龙判别法
考虑 $f(x) = x^6 + 2x^5 + 15x^4 + 3x^3 + x^2 + 2x + 1$

检查 $k=3$（$x^4$ 项系数）：
- $|a_3| = |15| = 15$
- $1 + \sum_{j \neq 3} |a_j| = 1 + 2 + 3 + 1 + 2 + 1 = 10$

由于 $15 > 10$，满足推广的佩龙条件，因此 $f(x)$ 在 $\mathbb{Q}$ 上不可约。
```

## 几何解释

### 根的位置分布
```ad-lemma
title: 佩龙条件与根的位置
如果多项式 $f(x) = x^n + a_{n-1}x^{n-1} + \cdots + a_0$ 满足佩龙条件，则：

1. $f(x)$ 在单位圆外恰好有一个根（称为**主导根**）
2. 其余 $n-1$ 个根都在单位圆内
3. 主导根是正实数
```

这种根的位置分布使得多项式无法分解为两个低次整系数多项式的乘积。

## 与其他判别法的比较

### 优势
```ad-lemma
title: 佩龙判别法的优点
1. **计算简单**：只需要计算系数的绝对值之和
2. **直接有效**：对于满足条件的多项式，结论确定
3. **适用范围**：对某些用其他方法难以判断的多项式有效
```

### 局限性
```ad-lemma
title: 佩龙判别法的局限
1. **充分非必要**：很多不可约多项式不满足佩龙条件
2. **对系数敏感**：系数的微小变化可能使判别法失效
3. **需要首一多项式**：要求多项式是首一的
```

## 变体与推广

### 1. 非首一情况
```ad-lemma
title: 非首一多项式的佩龙判别法
对于 $f(x) = a_nx^n + a_{n-1}x^{n-1} + \cdots + a_0 \in \mathbb{Z}[x]$，如果：

$$|a_k| > \sum_{j \neq k} |a_j| \quad \text{对某个 } 0 \leq k \leq n$$

且 $\gcd(a_0, a_1, \ldots, a_n) = 1$，则 $f(x)$ 在 $\mathbb{Q}$ 上不可约。
```

### 2. 佩龙-布拉乌尔定理
```ad-lemma
title: 佩龙-布拉乌尔定理
设 $f(x) = x^n + a_{n-1}x^{n-1} + \cdots + a_0 \in \mathbb{Z}[x]$。如果：

$$|a_{n-1}| \geq 1 + |a_{n-2}| + \cdots + |a_0|$$

且 $f(1) \neq 0$，$f(-1) \neq 0$，则 $f(x)$ 在 $\mathbb{Q}$ 上不可约。

这是佩龙判别法的弱化版本，允许等号成立。
```

## 实际应用技巧

### 1. 系数缩放技巧
```ad-example
title: 通过变量替换应用佩龙判别法
对于多项式 $f(x) = 2x^4 + 3x^3 + 5x^2 + x + 1$，虽然不是首一的，但可以考虑：

$$g(x) = x^4 f(1/x) = x^4 + x^3 + 5x^2 + 3x + 2$$

如果 $g(x)$ 满足佩龙条件，则 $f(x)$ 也不可约。
```

### 2. 结合其他判别法
```ad-lemma
title: 综合判别策略
1. 先尝试佩龙判别法（计算简单）
2. 如果不满足，尝试爱森斯坦判别法
3. 再尝试模约简测试
4. 最后考虑数值方法或专门算法
```
