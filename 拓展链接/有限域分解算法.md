## 1. 试除法 (Trial Division)

```ad-def
title: 试除法原理
通过检查多项式在有限域中是否有根来判断是否有一阶因子。

**算法步骤**：
1. 对于每个 $a \in \mathbb{F}_p$，计算 $f(a)$
2. 如果 $f(a) = 0$，则 $(x-a)$ 是 $f(x)$ 的一个因子
3. 用多项式除法得到商式，继续分解
```

```ad-example
title: 试除法示例
在 $\mathbb{F}_5$ 上分解 $f(x) = x^3 + 2x^2 + x + 2$：

- $f(0) = 2 \neq 0$
- $f(1) = 1 + 2 + 1 + 2 = 6 \equiv 1 \pmod{5} \neq 0$
- $f(2) = 8 + 8 + 2 + 2 = 20 \equiv 0 \pmod{5}$

因此 $(x-2)$ 是因子，$f(x) = (x-2)(x^2 + 4x + 4)$
```

**优缺点**：
- 优点：简单直观
- 缺点：当 $p$ 很大时效率低

## 2. 平方自由分解 (Square-Free Factorization)

```ad-def
title: 平方自由分解原理
去除多项式中的重因子，将其分解为无平方因子的多项式的乘积。

**核心思想**：
如果 $f(x)$ 有重因子，则 $f(x)$ 与其导数 $f'(x)$ 有公因子。
```

```ad-lemma
title: 平方自由分解算法
1. 计算 $d(x) = \gcd(f(x), f'(x))$
2. 如果 $d(x) = 1$，则 $f(x)$ 已经是平方自由的
3. 否则，令：
   - $g(x) = f(x)/d(x)$
   - $h(x) = d(x)$
4. 递归处理 $g(x)$ 和 $h(x)$
```

```ad-example
title: 平方自由分解示例
考虑 $f(x) = x^4 + 2x^3 + x^2 = x^2(x+1)^2$

计算：
- $f'(x) = 4x^3 + 6x^2 + 2x = 2x(2x^2 + 3x + 1)$
- $\gcd(f, f') = x(x+1)$
- $g(x) = f(x)/\gcd(f, f') = x(x+1)$
- $h(x) = \gcd(f, f') = x(x+1)$

最终得到平方自由分解：$f(x) = [x(x+1)]^2$
```

## 3. 不同次数因子分解 (Distinct Degree Factorization, DDF)

```ad-def
title: DDF 原理
将多项式分解为各个因子的不可约因子都具有相同次数的乘积。

**数学基础**：
在 $\mathbb{F}_p$ 上，多项式 $x^{p^d} - x$ 是所有次数整除 $d$ 的不可约多项式的乘积。
```

```ad-lemma
title: DDF 算法步骤
1. 输入：平方自由多项式 $f(x)$
2. 令 $i = 1$，$g(x) = f(x)$
3. 当 $\deg(g) > 0$ 且 $i \leq \frac{\deg(f)}{2}$ 时：
   - 计算 $h_i(x) = \gcd(g(x), x^{p^i} - x)$
   - 如果 $h_i(x) \neq 1$，则输出 $h_i(x)$ 作为 $i$ 次因子的乘积
   - 令 $g(x) = g(x)/h_i(x)$
   - $i = i + 1$
4. 如果 $\deg(g) > 0$，则 $g(x)$ 本身是不可约的
```

```ad-example
title: DDF 算法示例
在 $\mathbb{F}_2$ 上分解 $f(x) = x^5 + x^3 + x^2 + 1$：

- $i=1$：$\gcd(f, x^2-x) = x+1$（1次因子）
- 剩余 $g(x) = (x^5+x^3+x^2+1)/(x+1) = x^4+x^3+x+1$
- $i=2$：$\gcd(g, x^4-x) = x^2+x+1$（2次不可约因子）
- 剩余 $h(x) = g/(x^2+x+1) = x^2+1$（2次因子）

最终：$f(x) = (x+1)(x^2+x+1)(x^2+1)$
```

## 4. Cantor-Zassenhaus 算法

```ad-def
title: Cantor-Zassenhaus 算法
用于将 DDF 输出的相同次数的因子进一步分解为不可约因子的概率算法。

**适用条件**：已知多项式是若干相同次数的不可约多项式的乘积。
```

```ad-lemma
title: Cantor-Zassenhaus 算法步骤
1. 输入：$f(x)$ 是 $r$ 个 $d$ 次不可约多项式的乘积
2. 如果 $r = 1$，则 $f(x)$ 不可约，返回
3. 重复：
   - 随机选择次数 $< \deg(f)$ 的多项式 $h(x)$
   - 计算 $g(x) = \gcd(f(x), h(x))$
   - 如果 $g(x) \neq 1$ 且 $g(x) \neq f(x)$，则用 $g(x)$ 和 $f(x)/g(x)$ 递归分解
   - 否则，计算 $H(x) = h(x)^{\frac{p^d-1}{2}} \bmod f(x)$
   - 计算 $g(x) = \gcd(f(x), H(x)-1)$
   - 如果 $g(x) \neq 1$ 且 $g(x) \neq f(x)$，则成功分裂
```

```ad-example
title: Cantor-Zassenhaus 示例
在 $\mathbb{F}_3$ 上分解 $f(x) = x^4 + 1$（已知是两个二次不可约因子的乘积）：

随机选择 $h(x) = x+1$
- $H(x) = (x+1)^{\frac{3^2-1}{2}} \bmod f(x) = (x+1)^4 \bmod (x^4+1)$
- 计算得 $H(x) = 2x^3 + 2x^2 + 2x + 2$
- $\gcd(f(x), H(x)-1) = x^2 + x + 2$

得到分解：$f(x) = (x^2+x+2)(x^2+2x+2)$
```

## 5. Berlekamp 算法

```ad-def
title: Berlekamp 算法
确定性算法，通过线性代数方法分解多项式。

**核心思想**：利用 Frobenius 自同构的固定点。
```

```ad-lemma
title: Berlekamp 算法步骤
1. **构造 Berlekamp 矩阵**：
   - 计算 $x^{ip} \bmod f(x)$，$i=0,1,\ldots,n-1$
   - 构造矩阵 $Q$，其中第 $i$ 行是 $x^{ip} \bmod f(x)$ 的系数

2. **求解线性系统**：
   - 求解 $(Q-I)v = 0$，得到零空间基

3. **因子分解**：
   - 对每个非平凡的 $v$，计算 $\gcd(f(x), v(x)-c)$ 对所有 $c \in \mathbb{F}_p$
   - 得到 $f(x)$ 的因子
```

```ad-example
title: Berlekamp 算法示例
在 $\mathbb{F}_2$ 上分解 $f(x) = x^3 + x + 1$：

1. 计算：
   - $x^0 \equiv 1$
   - $x^2 \equiv x^2$
   - $x^4 \equiv x^2 + x \pmod{f(x)}$

2. 构造矩阵 $Q$ 并求解 $(Q-I)v=0$

3. 得到分解：$f(x)$ 在 $\mathbb{F}_2$ 上不可约
```

## 算法比较与选择

| 算法 | 类型 | 时间复杂度 | 适用场景 |
|------|------|------------|----------|
| **试除法** | 确定性 | $O(p \cdot n^2)$ | 小域，低次多项式 |
| **平方自由分解** | 确定性 | $O(n^3)$ | 预处理步骤 |
| **DDF** | 确定性 | $O(n^3 \log p)$ | 中等规模问题 |
| **Cantor-Zassenhaus** | 概率性 | $O(n^3 \log p)$ | 大域，高效实现 |
| **Berlekamp** | 确定性 | $O(n^3)$ | 小到中等域 |
