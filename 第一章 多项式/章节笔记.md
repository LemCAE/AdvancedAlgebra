## $\S 1$ 数域

```ad-def
title:数域
设 $P$ 是有一些复数组成的集合，其中包括 $0$ 与 $1$ .如果 $P$ 中任意两个数（这两个数也可以相同)的和、差、积、商（除数不为 $0$）仍然是 $P$ 中的数，那么 $P$ 就称为一个**数域**.
```

其中，$\mathbb{Q}, \mathbb{R},\mathbb{C}$ 分别表示**有理数域**，**实数域**以及**复数域**。有理数域 $\mathbb{Q}$ 是最小的数域。

```ad-def
title:数环
如果一个数集 $P$ 中的任意两个元素 $a, b$ 对加减法以及乘法[[封闭]]，这个数集 $P$ 称为一个**数环**
```

```ad-tip
实际上，如果一个数集包含至少包含两个元素且对除法以及减法封闭，这个数集就可以构成一个数域.
```

## $\S 2$ 一元多项式

### **多项式的定义**

```ad-def
title:一元多项式
设 $\mathbb{P}$ 是一个数域，$x$ 是一个符号或文字，
若
$$
f(x)=a_nx^n+a_{n-1}x^{n-1}+\cdots+a_1x+a_0,
\quad a_i\in\mathbb{P},\ a_n\ne0,
$$
则称 $f(x)$ 为**数域 $\mathbb{P}$ 上的一元多项式**。
```

记号与术语：

- $a_i$ 称为 $f(x)$ 的第 $i$ 次项系数；
- $a_nx^n$ 称为首项；
- $a_n$ 称为**首项系数**；
- $n$ 称为**多项式的次数**，记为 $\partial(f)=n$；
- 若所有系数均为 $0$，称为**零多项式**，记作 $f(x)=0$。

```ad-note

- 零多项式 $f(x)=0$ 不定义次数；
- 常数多项式 $f(x)=a\ne0$ 为零次多项式；
- 若 $a_n=1$，则称 $f(x)$ 为**首一多项式**。
```

---

```ad-def
title:多项式相等
若 $f(x),g(x)\in\mathbb{P}[x]$，并且
$$
f(x)-g(x)=0,
$$
即对应次数项的系数完全相等，则称 $f(x)$ 与 $g(x)$ **相等**，记作 $f(x)=g(x)$。
```

---

```ad-note
title:多项式运算
对 $f(x), g(x)\in\mathbb{P}[x]$ 定义：
$$
(f+g)(x)=f(x)+g(x),\quad (f-g)(x)=f(x)-g(x),\quad (fg)(x)=f(x)\cdot g(x)
$$
则 $(\mathbb{P}[x],+,·)$ 构成一个代数系统。
```

```ad-tip
title:说明
“$(\mathbb{P}[x],+,·)$ 构成一个代数系统”是指：  
在多项式集合 $\mathbb{P}[x]$ 上定义加法与乘法后，
该集合在这两种运算下封闭，并满足结合律、交换律与分配律，
因此它构成一个代数结构——即**环（Ring）**。

```

若  
$$  
f(x)=\sum_{i=0}^n a_i x^i,\quad g(x)=\sum_{j=0}^m b_j x^j,  
$$  
则：

- 加法：$(f+g)(x)=\sum_{k=0}^{\max(m,n)} (a_k+b_k)x^k$；
- 乘法：$(fg)(x)=\sum_{s=0}^{m+n} c_s x^s$，其中 $c_s=\sum_{i+j=s}a_i b_j$。

---

```ad-theorem
title:多项式次数的运算规律
若 $f(x),g(x)\in\mathbb{P}[x]$，且 $f,g\ne0$，则有：
1. $\partial(f\pm g)\le\max\{\partial(f),\partial(g)\}$；
2. $\partial(fg)=\partial(f)+\partial(g)$；
3. $\text{首项系数}(fg)=\text{首项系数}(f)\cdot\text{首项系数}(g)$。
```

```ad-proof
collapse:closed
设 $f(x)=a_nx^n+\cdots+a_0,\quad g(x)=b_mx^m+\cdots+b_0$。  
- 加减法中最高次项可能相消，故 $\partial(f\pm g)\le\max(n,m)$；
- 乘法时最高次项为 $a_nb_mx^{n+m}$，且 $a_nb_m\ne0$，故 $\partial(fg)=n+m$；
- 其首项系数即 $a_nb_m$。
```

---

```ad-def
title:多项式零因子与消去律
若 $f(x)g(x)=0$，且 $f(x),g(x)\in\mathbb{P}[x]$，
则必有 $f(x)=0$ 或 $g(x)=0$。
因此 $\mathbb{P}[x]$ 中不存在[[零因子]]，称为**整环**。
```

---
### **多项式的运算规律**

1. 加法交换律
2. 加法结合律
3. 乘法交换律
4. 乘法结合律
5. 乘法对加法的分配律
6. 乘法消去律

```ad-corollary
title:乘法消去律
若 $f(x),g(x),h(x)\in\mathbb{P}[x]$ 且 $h(x)\ne0$，若
$$
f(x)h(x)=g(x)h(x),
$$
则有 $f(x)=g(x)$。
```

```ad-proof
collapse:closed
由整环性质，$(f-g)h=0\Rightarrow f-g=0\Rightarrow f=g$。
```
---

```ad-def
title:多项式环
全体系数属于数域 $\mathbb{P}$ 的一元多项式所构成的集合记作
$$
\mathbb{P}[x],
$$
称为**数域 $\mathbb{P}$ 上的一元多项式环**。
```

该集合满足：

1. 对加、减、乘运算封闭；
2. 加法、乘法均满足交换律与结合律；
3. 乘法对加法满足分配律；
4. 存在单位元（$0$ 对加法，$1$ 对乘法）。

## $\S 3$ 整除的概念

### **带余除法**
```ad-def
title:带余除法定理
设 $\mathbb{P}$ 是一个数域，$f(x),g(x)\in\mathbb{P}[x]$ 且 $g(x)\ne0$，  
则存在唯一的 $q(x),r(x)\in\mathbb{P}[x]$，使得：
$$
f(x)=g(x)q(x)+r(x),\quad \partial(r)<\partial(g)\text{ 或 }r(x)=0.
$$
其中，$q(x)$ 称为**商式**，$r(x)$ 称为**余式**。
```

```ad-proof
collapse:closed
**（1）存在性）**  
设 $f(x)$ 的次数为 $n$，$g(x)$ 的次数为 $m$。  
若 $n<m$，则直接取 $q(x)=0, r(x)=f(x)$ 即可。  

若 $n\ge m$，记 $f(x)$ 与 $g(x)$ 的首项分别为 $a_nx^n, b_mx^m$，  
令
$$
f_1(x)=f(x)-\frac{a_n}{b_m}x^{n-m}g(x),
$$
则 $f_1(x)$ 的次数小于 $f(x)$。  

对 $f_1(x)$ 再次施行同样的步骤，继续减去适当倍数的 $g(x)$，  
如此反复，直到余式次数小于 $g(x)$，过程必定在有限步内结束。  
于是存在 $q(x),r(x)$ 满足要求。

---

**（2）唯一性）**  
若同时存在两组 $(q_1,r_1)$ 与 $(q_2,r_2)$ 使：
$$
f(x)=g(x)q_1(x)+r_1(x)=g(x)q_2(x)+r_2(x),
$$
则有
$$
g(x)\,[q_1(x)-q_2(x)]=r_2(x)-r_1(x).
$$
若 $r_1,r_2$ 均满足 $\partial(r_i)<\partial(g)$，  
则右边多项式次数 $<\partial(g)$，而左边若非零，其次数至少为 $\partial(g)$，  
故两边只能同为零。  
于是 $r_1=r_2, q_1=q_2$，唯一性得证。
```

---

```ad-def
title:整除
若 $f(x), g(x)\in\mathbb{P}[x]$，存在 $h(x)\in\mathbb{P}[x]$ 使
$$
f(x)=g(x)h(x),
$$
则称 $g(x)$ **整除** $f(x)$，记作 $g(x)\mid f(x)$，并称 $f(x)$ 是 $g(x)$ 的**倍式**，$g(x)$ 是 $f(x)$ 的**因式**。
```

```ad-note
title:特殊约定
- $0\mid0$ 有意义（零多项式可整除零多项式）；  
- $f(x)\mid0$ 对任意 $f(x)\in\mathbb{P}[x]$ 成立；  
- 但 $0\nmid f(x)$（除数不能为零多项式）。
```

---

```ad-theorem
title:定理1：整除的判定法
对 $f(x),g(x)\in\mathbb{P}[x]$，$g(x)\ne0$，  
若在带余除法中 $f(x)=g(x)q(x)+r(x)$ 且 $r(x)=0$，  
则 $g(x)\mid f(x)$；反之亦然。
```

```ad-proof
collapse:closed
若 $r(x)=0$，则 $f(x)=g(x)q(x)$，  
直接说明 $g(x)$ 整除 $f(x)$。  
反之，若 $f(x)=g(x)h(x)$，带余除法中余式为 $0$。
```

---

```ad-theorem
title:整除的基本性质
若 $f,g,h\in\mathbb{P}[x]$，则：
1. $f\mid f$；
2. 若 $f\mid g$ 且 $g\mid h$，则 $f\mid h$；
3. 若 $f\mid g$ 且 $f\mid h$，则 $f\mid(ag+bh)$ 对任意 $a,b\in\mathbb{P}$；
4. 若 $c\ne0$，则 $f\mid g\iff cf\mid cg$；
5. 若 $f,g\ne0$，则 $f\mid g$ 与 $g\mid f$ 当且仅当 $f=cg$，其中 $c\in\mathbb{P}^{\times}$。
```

```ad-proof
collapse:closed
1. 显然 $f(x)=f(x)\cdot1$。  
2. 若 $g=fh_1,\ h=h_1h_2f$，则 $h=f(h_1h_2)$。  
3. 若 $g=fh_1,h=fh_2$，则 $ag+bh=f(ah_1+bh_2)$。  
4. 由乘以非零常数不改变因式关系可直接验证。  
5. 若 $f\mid g,g\mid f$，则存在 $h_1,h_2$ 使 $f=h_1g,g=h_2f$，  
合并得 $f=(h_1h_2)f$，故 $h_1h_2=1$，两者相差一个非零常数。
```

---
### **整除性的常用性质**

1. $\forall f(x)\in\mathbb{P}[x],\Rightarrow f(x)|f(x), f(x)|0,\quad \forall a\in\mathbb{P}\text{且}a\neq0, a|f(x)$
2. 若 $f(x)|g(x),\Rightarrow af(x)|bg(x),\quad\forall a\in\mathbb{P}\text{且}a\neq0,b\in\mathbb{P}$ 
3. $f(x)|g(x), g(x)|f(x)\Rightarrow f(x)=cg(x)$ ,其中 $c$ 为非零常数
4. $f(x)|g(x),g(x)|h(x)\Rightarrow f(x)|h(x)$ *整除的传递性*
5. $f(x)|g_{i}(x),i=1,2,\cdots,r\Rightarrow$
	$$f(x)|\sum_{i=1}^{r}u_{i}(x)g_{i}(x)$$
	其中，$u_{i}$ 是数域 $\mathbb{P}$ 上任意的多项式
	$\sum_{i=1}^{r}u_{i}(x)g_{i}(x)$为一线性组合
6. $f(x)|g(x)\in\mathbb{P}[x],\mathbb{P}\subseteq\bar{\mathbb{P}}\Rightarrow\text{在}\bar{\mathbb{P}}[x]\text{中，}f(x)|g(x)$

---

```ad-corollary
title:零多项式的整除关系
- 任意多项式均可整除零多项式；
- 零多项式仅能整除自身；
- 非零常数多项式可整除任意多项式。
```

## $\S 4$ 最大公因式

### **一、最大公因式**

```ad-def
title:公因式与最大公因式
设 $f(x), g(x)\in \mathbb{P}[x]$，若存在 $d(x)\in \mathbb{P}[x]$，使
$$
d(x)\mid f(x),\quad d(x)\mid g(x),
$$
则称 $d(x)$ 为 $f(x)$ 与 $g(x)$ 的**公因式**。

若 $d(x)$ 是 $f(x),g(x)$ 的公因式，并且对任意公因式 $c(x)$ 都有
$$
c(x)\mid d(x),
$$
则称 $d(x)$ 为 $f(x),g(x)$ 的**最大公因式**，记作
$$
d(x)=\gcd(f(x),g(x)).
$$
```

```ad-note
title:说明
1. 最大公因式并不唯一，它仅在一个非零常数倍意义下唯一。  
   若 $d(x)$ 是一个最大公因式，则 $c\,d(x)$（$c\in\mathbb{P}^{\times}$）也是。  
   因此常取**首一多项式**作为最大公因式。  
2. 若 $\gcd(f,g)=1$，称 $f(x)$ 与 $g(x)$ **互素**。

```

```ad-theorem
title:引理
如果有等式
$$f(x)=q(x)g(x)+r(x)$$
成立，那么 $f(x)$，$g(x)$ 和 $r(x)$ 具有相同的公因式
```

```ad-proof
如果 $\varphi(x) \mid g(x)$，且 $\varphi(x) \mid r(x)$，那么由上式, $\varphi(x)\mid f(x)$ ，则 $r(x)$ 的公因式全是 $f(x), g(x)$ 的公因式。反过来，如果 $\varphi(x) \mid f(x), \quad \varphi(x) \mid g(x)$,那么 $\varphi(x)$ 一定整除它们的组合  
$$r(x) = f(x) - q(x)g(x)$$
这就是说，$\varphi(x)$ 是 $g(x), r(x)$ 的公因式。由此可见，如果 $g(x), r(x)$ 有一个最大公因式 $d(x)$，那么 $d(x)$ 也就是 $f(x), g(x)$ 的一个最大公因式。
```

---

```ad-theorem
title:定理2：贝祖等式
设 $f(x),g(x)\in\mathbb{P}[x]$ 且不全为零，  
令 $d(x)=\gcd(f(x),g(x))$，  
则存在 $u(x),v(x)\in\mathbb{P}[x]$，使得：
$$
d(x)=f(x)u(x)+g(x)v(x).
$$
```

```ad-proof
collapse:closed
**第一步：证明 $d(x) \mid f(x)$**  
对 $f(x)$ 和 $d(x)$ 做带余除法：  
$$f(x) = q(x) d(x) + r(x), \quad \deg r(x) < \deg d(x) \ \text{或} \ r(x) = 0.$$  
代入 $d(x) = f(x) u(x) + g(x) v(x)$：  
$$r(x) = f(x) - q(x)[f(x) u(x) + g(x) v(x)] = f(x)[1 - q(x) u(x)] + g(x)[-q(x) v(x)].$$  
若 $r(x) \neq 0$，则 $r(x) \in S$ 且 $\deg r(x) < \deg d(x)$，这与 $d(x)$ 是 $S$ 中次数最小的选择矛盾。  
因此 $r(x) = 0$，即 $d(x) \mid f(x)$。

同理可证 $d(x) \mid g(x)$。

---

**第二步：证明 $d(x)$ 是最大公因式**  
设 $h(x)$ 是 $f(x)$ 与 $g(x)$ 的任一公因式，则  
$$h(x) \mid f(x) u(x) + g(x) v(x) = d(x),$$  
所以 $\deg h(x) \le \deg d(x)$ 且 $h(x) \mid d(x)$。  
因此 $d(x)$ 是最大公因式（在相伴意义下唯一）。

---

**第三步：结论**  
我们找到的 $d(x)$ 满足  
$$d(x) = f(x) u(x) + g(x) v(x),$$  
且 $d(x)$ 是 $\gcd(f(x), g(x))$（可相差一个非零常数倍，不影响 Bézout 等式形式）。  
若将 $d(x)$ 取为首一最大公因式，只需对上述等式两边除以首项系数即可。

```

我们可以发现，两个多项式在可以相差一个非零常数倍的定义下是唯一确定的。

### **二、辗转相除法**

```ad-theorem
title:辗转相除法定理
设 $f(x),g(x)\in\mathbb{P}[x]$ 且 $f(x),g(x)\ne0$，  
利用带余除法作如下运算：
$$
\begin{aligned}
f(x)&=g(x)q_1(x)+r_1(x), &\partial(r_1)<\partial(g);\\
g(x)&=r_1(x)q_2(x)+r_2(x), &\partial(r_2)<\partial(r_1);\\
r_1(x)&=r_2(x)q_3(x)+r_3(x), &\partial(r_3)<\partial(r_2);\\
&\vdots\\
r_{k-2}(x)&=r_{k-1}(x)q_k(x)+r_k(x), &\partial(r_k)<\partial(r_{k-1});\\
r_{k-1}(x)&=r_k(x)q_{k+1}(x), &r_{k+1}(x)=0.
\end{aligned}
$$
则最后一个非零余式 $r_k(x)$ 即为 $f(x)$ 与 $g(x)$ 的最大公因式。
```

```ad-proof
collapse:closed
我们证明：最后一个非零余式 $r_k$ 同时满足：
1. $r_k\mid f, r_k\mid g$；  
2. 对任意公因式 $d$，若 $d\mid f,g$，则 $d\mid r_k$。

---

**（1）$r_k\mid f,g$）**  
由最后一步 $r_{k-1}=r_kq_{k+1}$ 知 $r_k\mid r_{k-1}$。  
由倒数第二步 $r_{k-2}=r_{k-1}q_k+r_k$ 知 $r_k\mid r_{k-2}$。  
依次上推，可得 $r_k\mid g$，再由第一式 $f=gq_1+r_1$，得 $r_k\mid f$。

---

**（2）若 $d\mid f,g$，则 $d\mid r_k$）**  
因为 $d\mid f,g$，由 $f=gq_1+r_1$ 得 $d\mid r_1$；  
再由 $g=r_1q_2+r_2$ 得 $d\mid r_2$；  
如此类推，最终 $d\mid r_k$。

---

综上，$r_k$ 满足最大公因式的定义。
```

---

```ad-note
title:辗转相除法的步骤总结
1. 用 $f$ 除以 $g$，得余式 $r_1$；  
2. 用 $g$ 除以 $r_1$，得余式 $r_2$；  
3. 继续用前一个除以后一个，直到余式为 $0$；  
4. 最后一个非零余式即为 $\gcd(f,g)$。
```

```ad-note
title:说明
每次除法余式的次数递减，因此辗转相除法必在有限步内终止。
```

```ad-def
title:互素
如果 $(f(x),g(x))=1$ ,则称 $\mathbb{P}[x]$中两个多项式 $f(x),g(x)$
```

```ad-theorem
title: 定理3：互素的等价条件
$\mathbb{P}[x]$中两个多项式$f(x),g(x)$互素的充要条件是有$\mathbb{P}[x]$中的多项式$u(x),v(x)$使得
$$u(x)f(x)+v(x)g(x)=1$$
```

```ad-proof
collapse:closed
贝祖等式的特例。当最大公因式为 1 时，即存在此线性表示。
```

```ad-theorem
title: 定理4
 $(f(x), g(x)) = 1, f(x) | g(x) h(x) \Rightarrow f(x) | h(x)$
```

```ad-proof
collapse:closed
$$(f(x), g(x)) = 1 \iff \exists u(x), v(x) \in P[x], u(x) f(x) + v(x) g(x) = 1$$
$$\Rightarrow u(x) f(x) h(x) + v(x) g(x) h(x) = h(x)$$
$$f(x) | g(x) h(x)$$
$$\Rightarrow f(x) | h(x)$$
```

```ad-corollary
如果$f(x) \mid h(x), g(x) \mid h(x), (f(x), g(x)) = 1 \Rightarrow f(x)g(x)\mid h(x)$
```

```ad-proof
$$f(x) \mid h(x) \Rightarrow h(x) = f(x)u(x)$$
$$g(x) \mid h(x)$$
$$(f(x), g(x)) = 1$$

$$g(x) \mid u(x)$$
$$u(x) = g(x)v(x)$$

$$h(x) = f(x)g(x)v(x)$$
```

### **三、若干推论**

```ad-corollary
title:最大公因式的性质
设 $f,g,h\in\mathbb{P}[x]$，则：
1. 若 $d=\gcd(f,g)$，则 $\gcd(f,g)=\gcd(g,f)$；
2. 若 $c\ne0$，则 $\gcd(cf,cg)=c\,\gcd(f,g)$；
3. 若 $\gcd(f,g)=1$ 且 $f\mid gh$，则 $f\mid h$；
4. 若 $f\mid g$，则 $\gcd(f,g)=f$。
```

```ad-proof
collapse:closed
(1) 对称性显然。  
(2) 因乘以常数不影响整除关系。  
(3) 由贝祖等式：存在 $u,v$ 使 $fu+gv=1$。两边乘以 $h$ 得 $f(uh)+g(vh)=h$。若 $f\mid gh$，则 $f\mid h$。  
(4) 若 $f\mid g$，则 $f$ 本身满足最大公因式定义。
```

### **四、多个多项式的最大公因式**

```ad-def
title:最大公因式的推广定义
$d(x), f_1(x), f_2(x), \cdots, f_s(x) \in \mathbb{P}[x], s \geq 2$。若

① $d(x)|f_i(x), i = 1, 2, \ldots, s;$

② $\forall \varphi(x) \in \mathbb{P}[x]$, 若 $\varphi(x)|f_i(x), i = 1, 2, \ldots, s \Rightarrow \varphi(x)|d(x)$。

则称 $d(x)$ 为 $f_1(x), f_2(x), \cdots, f_s(x)$ 的最大公因式。
```


① $f_1(x), f_2(x), \cdots, f_s(x)$ 的最大公因式一定存在，且它们首项系数为1的最大公因式记为 $(f_1(x), f_2(x), \cdots, f_s(x))$。

② $\exists u_1, u_2 \cdots u_s \in \mathbb{P}[x], \exists (f_1, f_2, \cdots, f_s) = u_1 f_1 + \cdots + u_s f_s$。

③ $(f_1, f_2, \cdots, f_s) = ((f_1, f_2, \cdots, f_{s-1}), f_s)$

④ $f_1, f_2, \cdots, f_s$ 互素 $\Leftrightarrow (f_1, f_2, \cdots, f_s) = 1$
   $$\Leftrightarrow \exists u_1, u_2, \cdots, u_s \in \mathbb{P}[x], u_1 f_1 + \cdots + u_s f_s = 1$$

⑤ $(f_1(x), f_2(x), \cdots, f_s(x)) = 1 \Rightarrow (f_i(x), f_j(x)) = 1$
   $\exists i, j, (f_i(x), f_j(x)) = 1 \Rightarrow (f_1(x), f_2(x), \cdots, f_s(x)) = 1$

## $\S 5$ 不可约多项式

### 一、不可约多项式的定义

```ad-def
title:定义8 不可约多项式
设 $f(x)\in \mathbb{P}[x]$ 且 $\deg f(x) \ge 1$。  
若 $f(x)$ 不能写成两个次数低于它的非常数多项式的乘积，即
$$
f(x)=g(x)h(x)\Rightarrow \text{$g(x)$ 或 $h(x)$ 为常数多项式，}
$$
则称 $f(x)$ 在域 $\mathbb{P}$ 上**不可约**。  
否则称为**可约多项式**。
```

```ad-note
title:说明
1. 不可约性的判断依赖于系数域。例如：  
   - $x^2+1$ 在 $\mathbb{R}[x]$ 不可约；  
   - 但在 $\mathbb{C}[x]$ 可约（$x^2+1=(x+i)(x-i)$）。  
2. 一次多项式必不可约。  
3. 若 $f(x)$ 不可约，则其任意非零常数倍 $c f(x)$ 亦不可约。  
4. 若 $f(x)$ 可约，则必存在次数大于 0 的公因式。
```

---

### 二、不可约多项式的基本性质

```ad-theorem
title:定理5 不可约多项式的整除性质
设 $p(x)$ 是 $\mathbb{P}[x]$ 上的不可约多项式。若 $p(x)\mid f(x)g(x)$，  
则 $p(x)\mid f(x)$ 或 $p(x)\mid g(x)$。
```

```ad-proof
collapse:closed
若 $p\nmid f$，则 $\gcd(p,f)=1$。  
由贝祖等式，存在 $u,v\in\mathbb{P}[x]$ 使得
$$
p(x)u(x)+f(x)v(x)=1。
$$
两边乘以 $g(x)$ 得
$$
g(x)=p(x)(u(x)g(x))+f(x)(v(x)g(x))。
$$
因 $p\mid f(x)g(x)$，从而 $p\mid g(x)$。
```

---

```ad-corollary
title:推论1
若 $p(x)$ 不可约，且 $p(x)\mid f_1(x)f_2(x)\cdots f_n(x)$，  
则 $p(x)$ 至少整除其中一个 $f_i(x)$。
```

```ad-proof
collapse:closed
用数学归纳法。  
$n=2$ 时结论即为定理。  
若 $n>2$，设 $p\mid f_1\cdots f_n$。  
若 $p\nmid f_n$，则 $p\mid f_1\cdots f_{n-1}$，由归纳假设得证。
```

---

### 三、因式分解存在定理

```ad-theorem
title:定理6 多项式的因式分解存在定理
任意非零非常数多项式 $f(x)\in\mathbb{P}[x]$，  
都可表示为若干不可约多项式的乘积：
$$
f(x)=p_1(x)p_2(x)\cdots p_r(x),
$$
其中各 $p_i(x)$ 不可约。
```

```ad-proof
collapse:closed
用次数归纳法。  
若 $\deg f=1$，结论显然成立。  
设对次数小于 $n$ 的多项式结论成立。  
当 $\deg f=n>1$ 时：  
- 若 $f$ 不可约，结论成立；  
- 若 $f$ 可约，则 $f=g h$，其中 $\deg g,\deg h<n$。  
由归纳假设，$g,h$ 均可分解为不可约多项式之积，  
因此 $f$ 也能分解为不可约多项式的积。
```

---

### 四、因式分解唯一性定理

```ad-theorem
title:定理7 多项式因式分解唯一性定理
设 $f(x)\in\mathbb{P}[x]$。若存在两个不可约分解：
$$
f(x)=p_1p_2\cdots p_r=q_1q_2\cdots q_s,
$$
其中每个 $p_i,q_j$ 均为首一不可约多项式，  
则 $r=s$，并可重新排列使 $p_i=q_i$。
```

```ad-proof
collapse:closed
由存在定理得分解式必存在。  
取 $p_1$，因 $p_1\mid q_1q_2\cdots q_s$，  
由定理5 有 $p_1\mid q_j$ 对某 $j$ 成立。  
两者均首一、不可约，故 $p_1=q_j$。  
消去该因式后，对余式重复此过程，归纳得 $r=s$ 且 $p_i=q_i$。
```

---

### 五、标准分解式

```ad-def
title:标准分解式
若
$$
f(x)=a\,p_1^{k_1}(x)p_2^{k_2}(x)\cdots p_t^{k_t}(x)
$$
是 $f(x)$ 的分解式，且各 $p_i(x)$ 首一并互素，  
则称此式为 $f(x)$ 的**标准分解式**。
```

```ad-corollary
title:推论2
多项式的标准分解式在 $\mathbb{P}[x]$ 中是唯一的。
```

---

```ad-corollary
title:命题1
两个不同的首项系数等于 1 的不可约多项式互素。
```

```ad-proof
collapse:closed
设 $p(x),q(x)$ 不可约，且 $d(x)=(p(x),q(x))\ne1$。  
则 $d(x)=p(x)$ 或 $d(x)=q(x)$，两者必居其一。  
于是有 $p(x)\mid q(x)$ 或 $q(x)\mid p(x)$，与“不同”矛盾。  
故 $d(x)=1$。
```

---

```ad-corollary

f(x)=c_1p_1^{r_1}(x)p_2^{r_2}(x)\cdots p_s^{r_s}(x),\quad
```

## $\S 6$ 重因式
### 一、不可约多项式

```ad-def
title:不可约多项式
设 $f(x)\in\mathbb{P}[x]$ 且 $\partial(f)\ge1$。  
若 $f(x)$ 不是两个次数低于它的多项式的积，即  
$$
f(x)=g(x)h(x)\Rightarrow \text{至少有一个为常数多项式，}
$$
则称 $f(x)$ 在 $\mathbb{P}$ 上**不可约**。  
若可分解为非常数因式之积，则称为**可约**。
```

```ad-note
title:说明
- 不可约性的讨论**依赖于系数域**：  
  例如 $x^2+1$ 在 $\mathbb{R}[x]$ 不可约，但在 $\mathbb{C}[x]$ 可约；
- 常数多项式既不称为可约也不称为不可约。
```

---

### 二、基本性质

```ad-theorem
title:不可约多项式的整除性质
设 $p(x)$ 是 $\mathbb{P}$ 上不可约多项式。若 $p(x)\mid f(x)g(x)$，  
则有 $p(x)\mid f(x)$ 或 $p(x)\mid g(x)$。
```

```ad-proof
collapse:closed
若 $p\nmid f$，则 $\gcd(p,f)=1$（否则有非常数公因式，违不可约性）。  
由贝祖等式，存在 $u,v\in\mathbb{P}[x]$ 使 $p u+f v=1$。  
两边乘以 $g$ 得：
$$
g=p(ug)+f(vg)。
$$
因 $p\mid fg$，$p\mid f(vg)$，从而 $p\mid g$。
```

---

```ad-corollary
title:不可约多项式的互素性推论
若 $p$ 为不可约多项式且 $p\nmid f$，则 $\gcd(p,f)=1$。
```

---

```ad-corollary
title:不可约多项式的传递整除性
若 $p$ 不可约，且 $p\mid f_1f_2\cdots f_n$，  
则 $p$ 至少整除其中一个 $f_i$。
```

```ad-proof
collapse:closed
对 $n$ 用数学归纳法。  
$n=2$ 时结论成立。  
若 $n>2$，由 $p\mid (f_1f_2\cdots f_{n-1})f_n$，  
若 $p\mid f_n$ 结论成；否则 $p\nmid f_n$，则 $p\mid f_1\cdots f_{n-1}$，  
由归纳假设得证。
```

---

### 三、因式分解存在定理

```ad-theorem
title:因式分解存在定理
任意非零、非单位多项式 $f(x)\in\mathbb{P}[x]$，  
都可分解为若干不可约多项式的积：
$$
f(x)=p_1(x)p_2(x)\cdots p_r(x),
$$
其中每个 $p_i(x)$ 在 $\mathbb{P}[x]$ 上不可约。
```

```ad-proof
collapse:closed
若 $\partial(f)=1$，显然成立。  
设对次数小于 $n$ 的多项式结论成立。  
当 $\partial(f)=n$ 时：  
若 $f$ 不可约，结论成立；  
若可约，则 $f=g h$，其中 $\partial(g),\partial(h)<n$。  
由归纳假设，$g,h$ 各可分解为不可约多项式之积，  
两者相乘即得 $f$ 的分解式。
```

---

### 四、因式分解唯一性定理

```ad-theorem
title:因式分解唯一性定理
设 $f(x)\in\mathbb{P}[x]$，  
若
$$
f(x)=p_1p_2\cdots p_r=q_1q_2\cdots q_s
$$
是 $f(x)$ 的两个不可约分解（各因式皆首一），  
则 $r=s$，且存在重排使 $p_i=q_i$ 对每个 $i$ 成立。
```

```ad-proof
collapse:closed
由存在定理得分解式存在。  
我们证明唯一性。  
令 $p_1\mid q_1q_2\cdots q_s$，因 $p_1$ 不可约，  
由不可约整除性质可得 $p_1\mid q_j$ 对某个 $j$ 成立。  
因两者均首一、不可约，故 $p_1=q_j$。  
两边消去 $p_1=q_j$，对余式继续同理，归纳得所有因式对应相等。
```

---

```ad-corollary
title:多项式环的唯一分解性
数域 $\mathbb{P}$ 上的一元多项式环 $\mathbb{P}[x]$ 是**唯一分解整环**（UFD）。
```

---

### 五、小结

```ad-summary
title:本节要点
- **不可约定义：** $f=gh$ ⇒ $g$ 或 $h$ 为常数；
- **依域性：** 不可约性取决于系数域；
- **不可约整除性质：** $p\mid fg$ ⇒ $p\mid f$ 或 $p\mid g$；
- **存在性：** 每个非零多项式都可分解为有限个不可约因式；
- **唯一性：** 分解唯一（除顺序与常数倍外）；
- **结论：** $\mathbb{P}[x]$ 是唯一分解整环（UFD）。
```

## $\S 7$ 多项式函数
### 一、根与因式的关系

```ad-def
title:多项式的根
设 $f(x)\in\mathbb{P}[x]$，$a\in\mathbb{P}$。  
若 $f(a)=0$，则称 $a$ 为 $f(x)$ 的一个**根**（或**零点**）。
```

```ad-theorem
title:因式定理
设 $f(x)\in\mathbb{P}[x]$，$a\in\mathbb{P}$。  
则下列两命题等价：
1. $a$ 是 $f(x)$ 的根；
2. $(x-a)\mid f(x)$。
```

```ad-proof
collapse:closed
由带余除法得：
$$
f(x)=(x-a)q(x)+r,
$$
其中 $r\in\mathbb{P}$。  
令 $x=a$ 得 $f(a)=r$。  
若 $f(a)=0$，则 $r=0$，即 $f(x)=(x-a)q(x)$；  
反之亦然。  
```

---

```ad-corollary
title:根的个数上界
设 $f(x)\in\mathbb{P}[x]$，$\partial(f)=n>0$，  
则在 $\mathbb{P}$ 中，$f(x)$ 至多有 $n$ 个不同的根。
```

```ad-proof
collapse:closed
若 $f$ 有 $k$ 个不同的根 $a_1,\dots,a_k$，  
则由因式定理可得
$$
(x-a_1)\cdots(x-a_k)\mid f(x)。
$$
故 $\partial(f)\ge k$。
```

---

### 二、重根与单根

```ad-def
title:重根与单根
设 $f(x)\in\mathbb{P}[x]$，若 $a$ 为其根。  
若 $(x-a)^k\mid f(x)$ 且 $(x-a)^{k+1}\nmid f(x)$，  
则称 $a$ 为 $f(x)$ 的**$k$ 重根**。  
其中 $k=1$ 称为**单根**。
```

```ad-corollary
title:判别重根的导数条件
若 $a$ 是 $f(x)$ 的根，则：
- 若 $f'(a)\ne0$，则 $a$ 是单根；
- 若 $f'(a)=0$，则 $a$ 至少是二重根；
- 一般地，若 $f(a)=f'(a)=\cdots=f^{(k-1)}(a)=0$ 而 $f^{(k)}(a)\ne0$，  
  则 $a$ 是 $k$ 重根。
```

```ad-proof
collapse:closed
设 $f(x)=(x-a)^k g(x)$，且 $g(a)\ne0$。  
则
$$
f'(x)=k(x-a)^{k-1}g(x)+(x-a)^k g'(x)。
$$
代入 $x=a$ 得 $f(a)=0$，$f'(a)=0$ 当且仅当 $k\ge2$，  
一般情况依次类推。
```

---

```ad-theorem
title:无重根的充分必要条件
多项式 $f(x)$ **无重根**的充要条件是：
$$
\gcd(f(x),f'(x))=1。
$$
```

```ad-proof
collapse:closed
若 $f$ 有重根 $a$，则 $(x-a)^2\mid f$，并且 $(x-a)\mid f'$，  
因此 $(x-a)\mid\gcd(f,f')$，非互素；  
反之，若 $\gcd(f,f')\ne1$，则存在非常数因式 $d$ 使 $d\mid f,f'$，  
其根即为 $f$ 的重根。
```

---

### 三、分解定理

```ad-theorem
title:根与因式分解定理
设 $f(x)\in\mathbb{P}[x]$，若其在 $\mathbb{P}$ 中有 $n$ 个根（重数计入）  
$a_1,a_2,\dots,a_n$，  
则有
$$
f(x)=a_n(x-a_1)(x-a_2)\cdots(x-a_n)，
$$
其中 $a_n$ 为首项系数。
```

```ad-proof
collapse:closed
由因式定理，若 $a_1$ 是根，则 $f(x)=(x-a_1)q_1(x)$。  
若 $a_2$ 是 $q_1(x)$ 的根，则 $q_1(x)=(x-a_2)q_2(x)$，  
如此递推，最终可得上式。
```

---

```ad-corollary
title:首一化形式
若 $f(x)$ 为首一多项式且有根 $a_1,\dots,a_n$，  
则
$$
f(x)=(x-a_1)(x-a_2)\cdots(x-a_n)。
$$
```

---

### 四、复数域与实数域情形

```ad-theorem
title:代数基本定理
在复数域 $\mathbb{C}$ 上，任何非常数多项式都至少有一个复根。
```

```ad-corollary
title:复数域上的完全分解
每个 $f(x)\in\mathbb{C}[x]$ 都能完全分解为一次因式：
$$
f(x)=a_n(x-a_1)(x-a_2)\cdots(x-a_n)。
$$
```

---

```ad-corollary
title:实数域上的分解形式
任意实系数多项式 $f(x)\in\mathbb{R}[x]$ 可唯一分解为
$$
f(x)=a_n(x-a_1)\cdots(x-a_r)
[(x^2+b_1x+c_1)\cdots(x^2+b_sx+c_s)],
$$
其中每个二次因式的判别式 $b_i^2-4c_i<0$。
```

```ad-proof
collapse:closed
由复数域完全分解得根成对出现，  
共轭根乘积为实系数二次因式，整理得上式。
```

---

### 五、小结

```ad-summary
title:本节要点
- **因式定理：** $a$ 是根 ⇔ $(x-a)\mid f(x)$；
- **根的个数：** 不超过次数；
- **重根定义：** $(x-a)^k\mid f$ 且 $(x-a)^{k+1}\nmid f$；
- **判别式条件：** $f,f'$ 互素 ⇔ 无重根；
- **分解定理：** 若有 $n$ 个根则 $f(x)=a_n\prod (x-a_i)$；
- **域上的情况：**
  - 在 $\mathbb{C}$ 上完全分解；
  - 在 $\mathbb{R}$ 上分解为一次与不可约二次因式；
- **结论：** 根的结构决定多项式的代数分解形式。
```

## $\S 8$ 复系数与实系数多项式的因式分解
### 一、复数域上的因式分解

```ad-theorem
title:代数基本定理（再述）
在复数域 $\mathbb{C}$ 上，任意次数 $n\ge1$ 的多项式  
$$
f(x)=a_nx^n+a_{n-1}x^{n-1}+\cdots+a_0,\quad a_i\in\mathbb{C},\ a_n\ne0
$$
至少有一个复根。
```

```ad-corollary
title:完全分解定理
复系数多项式在 $\mathbb{C}$ 上可完全分解为一次因式的积：
$$
f(x)=a_n(x-\alpha_1)(x-\alpha_2)\cdots(x-\alpha_n)，
$$
其中 $\alpha_1,\dots,\alpha_n\in\mathbb{C}$ 为 $f(x)$ 的根（重数计入）。
```

```ad-note
title:说明
- 每个根的重数等于其出现的因式次数；
- 因式顺序任意，重根自动对应因式重复；
- 若 $f$ 为首一多项式，则 $a_n=1$。
```

---

### 二、实数域上的因式分解

```ad-theorem
title:复共轭根定理
若 $f(x)\in\mathbb{R}[x]$，且 $\alpha=a+bi$（$b\ne0$）为其根，  
则其共轭复数 $\overline{\alpha}=a-bi$ 亦为 $f(x)$ 的根。
```

```ad-proof
collapse:closed
对任意实系数 $a_k$，有 $\overline{a_k}=a_k$。  
若 $f(\alpha)=0$，则
$$
0=\overline{f(\alpha)}=\overline{\sum a_k\alpha^k}
=\sum a_k\overline{\alpha}^k=f(\overline{\alpha})。
$$
故 $\overline{\alpha}$ 也是根。
```

---

```ad-corollary
title:实数域上的标准分解式
任意 $f(x)\in\mathbb{R}[x]$ 可唯一分解为
$$
f(x)=a_n(x-a_1)\cdots(x-a_r)
[(x^2+b_1x+c_1)\cdots(x^2+b_sx+c_s)]，
$$
其中：
- $a_i\in\mathbb{R}$；
- 各 $(x^2+b_jx+c_j)$ 对应复共轭根成对的因式；
- $b_j^2-4c_j<0$。
```

```ad-proof
collapse:closed
由复数域完全分解得：
$$
f(x)=a_n(x-\alpha_1)\cdots(x-\alpha_n)，
$$
实根单独保留，复根成对 $\alpha_j,\overline{\alpha_j}$ 合并：
$$
(x-\alpha_j)(x-\overline{\alpha_j})
=x^2-2(\Re\alpha_j)x+|\alpha_j|^2，
$$
系数实，判别式为负。合并即得上式。
```

---

### 三、分解的唯一性与结构

```ad-theorem
title:实数域上分解的唯一性
上式中的一次因式与不可约二次因式（顺序与常数倍除外）是唯一的。
```

```ad-proof
collapse:closed
若存在另一组分解式，转入复数域比较根集合。  
因复数域分解唯一，实根与共轭对的组合方式唯一，  
从而实分解唯一（仅差常数倍与因式次序）。
```

---

```ad-corollary
title:实多项式的不可约性
在 $\mathbb{R}[x]$ 中，  
多项式不可约当且仅当它是一阶或不可约二次多项式：
$$
\text{即 }\partial(f)=1
\text{ 或 }( \partial(f)=2,\ b^2-4c<0 )。
$$
```

### 四、根与系数的关系

```ad-theorem
title:根与系数关系式（韦达定理）
若
$$
f(x)=a_n(x-\alpha_1)(x-\alpha_2)\cdots(x-\alpha_n)
=a_nx^n+a_{n-1}x^{n-1}+\cdots+a_0，
$$
则：
$$
\begin{aligned}
\alpha_1+\alpha_2+\cdots+\alpha_n &= -\frac{a_{n-1}}{a_n},\\
\sum_{i<j}\alpha_i\alpha_j &= \frac{a_{n-2}}{a_n},\\
&\vdots\\
\alpha_1\alpha_2\cdots\alpha_n &= (-1)^n\frac{a_0}{a_n}.
\end{aligned}
$$
```

```ad-proof
collapse:closed
展开 $a_n(x-\alpha_1)\cdots(x-\alpha_n)$ 并比较各次幂系数即可。
```

### 五、小结

```ad-summary
title:本节要点
- **复数域：** 每个多项式都可分解为一次因式；
- **代数基本定理：** $\mathbb{C}$ 上无不可约多项式；
- **复共轭根定理：** 实多项式的复根成共轭对出现；
- **实数域分解：** 仅含一次与不可约二次因式；
- **唯一性：** 分解式除顺序与常数倍外唯一；
- **韦达定理：** 系数与根的基本对称关系。
```

## $\S 9$ 有理系数多项式
### 一、有理系数多项式与整系数多项式

```ad-def
title:有理系数多项式与整系数多项式
若多项式的各系数属于有理数域 $\mathbb{Q}$，则称其为**有理系数多项式**，  
其全体记作 $\mathbb{Q}[x]$。  
若系数均为整数，则称为**整系数多项式**，全体记作 $\mathbb{Z}[x]$。
```

```ad-note
title:说明
显然 $\mathbb{Z}[x]\subset\mathbb{Q}[x]$。  
对于任意 $f(x)\in\mathbb{Q}[x]$，存在最小公分母 $m$，使得 $mf(x)\in\mathbb{Z}[x]$。  
因此讨论 $\mathbb{Q}[x]$ 的性质常可化为 $\mathbb{Z}[x]$ 的研究。
```

---

### 二、本原多项式与高斯引理

```ad-def
title:本原多项式
如果一个非零的整系数多项式 $g(x)=\sum\limits^{n}_{i=0}a_ix^i$ 的系数 $a_n,a_{n-1},\cdots,a_0$ 没有异于 $\pm1$ 的公因子（即其互素），则称为**本原多项式**。  
本原多项式的表示方式是唯一的，两个相同的本原多项式之间只可能相差一个正负号。
```

显然，所有的有理系数多项式都可以通过乘上一个有理数使其化为本原多项式。

---

```ad-theorem
title:定理10：高斯引理
两个本原多项式的乘积仍是本原多项式。
```

```ad-proof
collapse:closed
设 
$$f(x)=a_{n}x^{n}+a_{n-1}x^{n-1}+\cdots+a_{1}x+a_{0}$$
$$g(x)=b_{m}x^{m}+b_{m-1}x^{m-1}+\cdots+b_{1}x+b_{0}$$
均为本原多项式，且
$$h(x)=f(x)g(x)=d_{n+m}x^{n+m}+d_{n+m-1}x^{n+m-1}+\cdots+d_{1}x+d_{0}$$
现假设 $h(x)$ 不是本原多项式，即其系数存在一个异于 $\pm1$ 的公因子，即有素数 $p$ 使得 $p$ 可以整除 $h(x)$ 的所有系数。
又因为 $f(x)$ 为本原多项式，则 $p$ 必然不能同时整除 $f(x)$ 的所有系数。不妨假设从 $a_0$ 开始，第一个不能被整除的系数为 $a_i$ ，故有：
$$p|a_{0},p|a_{1},\cdots,p|a_{i-1},p\nmid a_{i}$$
同理，对于 $g(x)$，有：
$$p|b_{0},p|b_{1},\cdots,p|b_{j-1},p\nmid b_{j}$$
又可知 $h(x)$ 的所有系数可以被 $p$ 整除，而其系数 $d_{i+j}$ 有：
$$d_{i+j}=a_{i}b_{j}+a_{i-1}b_{j+1}+\cdots+a_{i+1}b_{j-1}+\cdots$$
其中，$a_{i-1}b_{j+1},\cdots,a_{i+1}b_{j-1},\cdots$ 显然能被 $p$ 整除（ $p|a_{0},p|a_{1},\cdots,p|a_{i-1},p|b_{0},p|b_{1},\cdots,p|b_{j-1}$ ）
而 $a_{i}b_{j}$ 不能被 $p$ 整除（ $p\nmid a_{i},p\nmid b_{j}$ ）
故矛盾。
因此对于 $h(x)$ 的系数，不存在一个异于 $\pm1$ 的公因子，
即 $h(x)$ 也为本原多项式。
```

### 三、有理分解与整数分解

```ad-theorem
title:定理11
如果一个非零的整系数多项式能够分解成两个次数较低的有理系数多项式的乘积（在有理数域上可约），它一定能够分解成两个次数较低的整系数多项式的乘积（在整数环上可约）。
```

```ad-proof
collapse:closed
假设有一个非零整系数多项式 $f(x)$ ，其满足
$$f(x)=g(x)h(x)$$
其中 $g(x),h(x)$为次数低于 $f(x)$ 的非零整系数多项式。
不妨再设
$$f(x)=af_{i}(x),\quad g(x)=bg_{i}(x),\quad h(x)=ch_{i}(x)$$
其中 $a$ 为整数，$b,c$ 为有理数，
使得 $f_{i}(x),g_{i}(x),h_{i}(x)$ 均为本原多项式。
则
$$af_{i}(x)=bg_{i}(x)ch_{i}(x)=bcg_{i}(x)h_{i}(x)$$
即$f_{i}(x),g_{i}(x)h_{i}(x)$均为本原多项式。
又由其乘以系数 $a,bc$ 后相等，而 *本原多项式的表示方式是唯一的，两个相同的本原多项式之间只可能相差一个正负号*，
故可知 $\frac{bc}{a}=\pm1$，即 $bc$ 也为整数。
故其可以被分解成次数较低的整系数多项式的乘积。
```

---

```ad-corollary
title:推论11.1
设 $f(x),g(x)$ 是整系数多项式，且 $g(x)$ 是本原多项式。  
如果 $f(x)=g(x)h(x)$，其中 $h(x)$ 为有理系数多项式，那么 $h(x)$ 一定是整系数多项式。
```

```ad-proof
collapse:closed
$$f(x) \triangleq a f_1(x), \quad h(x) \triangleq c h_1(x), \quad a \in \mathbb{Z},\ c \in \mathbb{Q},$$
$f_1(x), h_1(x)$本原。
$$\Rightarrow a f_1(x) = g(x) \cdot c h_1(x) = c g(x) h_1(x)$$
$$\Rightarrow c = \pm a \Rightarrow c \in \mathbb{Z} \Rightarrow h(x) = c h_1(x)$$
为整系数多项式。
```

```ad-corollary
title:推论11.2
设 $f(x)$ 为本原多项式且其在 $\mathbb{Q}[x]$ 上可约，则 $f(x)$ 可以被分解成两个本原多项式的积。
```

```ad-proof
collapse:closed
设 $f(x)=g(x)h(x), g(x),h(x)\in\mathbb{Q}[x]$。  
若其中一个非本原, 则 $f(x)$ 非本原。
```

```ad-corollary
title:推论11.3
如果 $f(x),g(x)$ 为本原多项式且 $f(x)=g(x)h(x)$ ，则 $h(x)$ 也为本原多项式。
```

```ad-proof
collapse:closed
由推论11.1可知, $h(x)$ 为整系数多项式。  
若 $h(x)$ 非本原, 则 $f(x)$ 非本原。  
所以 $h(x)$ 必是本原的。
```

### 四、有理根判别定理

```ad-theorem
title:定理12：有理根定理
设
$$f(x)=a_{n}x^{n}+a_{n-1}x^{n-1}+\cdots+a_{1}x+a_{0}$$
是一个整系数多项式，若 $\frac{r}{s}$ 是它的一个最简有理根（$\gcd(r,s)=1$），则
$$s\mid a_{n},\quad r\mid a_{0}。$$
特别地，若 $a_n=1$，则 $f(x)$ 的有理根必为整数，且为 $a_0$ 的因子。
```

```ad-proof
collapse:closed
由题意 $(x-\frac{r}{s})\mid f(x)$，  
即 $(sx-r)\mid f(x)$。  
由于 $r,s$ 互素，故 $(sx-r)$ 为本原多项式。  
由 *推论11.1* 可知：
$$f(x)=(sx-r)(b_{n-1}x^{n-1}+b_{n-2}x^{n-2}+\cdots+b_{1}x+b_{0})。$$
比较首项与常数项系数得：
$$a_{n}=s b_{n-1},\quad a_{0}=r b_{0}。$$
因此 $s\mid a_n,\ r\mid a_0$。
```

### 五、爱森斯坦判别法

```ad-theorem
title:定理13：Eisenstein 判别法
设
$$f(x)=a_{n}x^{n}+a_{n−1}x^{n−1}+⋯+a_{1}x+a_{0}$$
是一个整系数多项式。  
若存在素数 $p$ 使得：
1. $p\nmid a_n$；
2. $p\mid a_i$ 对所有 $i=0,1,\dots,n-1$；
3. $p^2\nmid a_0$；
则 $f(x)$ 在有理数域 $\mathbb{Q}$ 上**不可约**。
```

```ad-proof
collapse:closed
若 $f(x)$ 可约，则
$$f(x)=(b_{l}x^{l}+b_{l-1}x^{l-1}+\cdots+b_{1}x+b_{0})(c_{m}x^{m}+c_{m-1}x^{m-1}+\cdots+c_{1}x+c_{0})。$$
比较系数有 $a_n=b_l c_m,\ a_0=b_0 c_0$。  
由条件 $p\mid a_0$ 且 $p^2\nmid a_0$，可知 $p$ 仅整除 $b_0$ 或 $c_0$ 中之一。  
不妨设 $p\mid b_0,\ p\nmid c_0$。  
由 $p\nmid a_n$ 知 $p\nmid b_l,c_m$。  

设从 $b_0$ 起第一个不被 $p$ 整除的系数为 $b_k$，  
则由展开式中
$$a_k=b_0 c_k+b_1 c_{k-1}+\cdots+b_{k-1} c_1+b_k c_0$$
知前几项都被 $p$ 整除，而 $b_k c_0$ 不被整除。  
这与 $p\mid a_k$ 矛盾。  
因此 $f(x)$ 不可约。
```

### 六、小结

```ad-summary
title:本节要点
- **本原多项式：** 系数无非 $\pm1$ 的公因子；
- **高斯引理：** 本原多项式乘积仍本原；
- **有理与整系数分解：** 在 $\mathbb{Q}[x]$ 可约 ⇔ 在 $\mathbb{Z}[x]$ 可约；
- **有理根定理：** 若 $\frac{r}{s}$ 是根，则 $s\mid a_n,\ r\mid a_0$；
- **Eisenstein 判别法：** 检验整系数多项式的不可约性；
- **总结：** $\mathbb{Z}[x]$ 中的分解问题可通过本原化、整除与素数条件判别来研究。
```
